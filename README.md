# My Wok — Website

Einseitige Restaurant-Website im Cartoon-Stil (dicke Konturen, harte Schatten, SVG-Illustrationen)
in Wok-Rot, Safran, Jade und Creme. Alles steckt in `index.html`; extern geladen werden nur die
Schriften *Fraunces* und *Nunito* von Google Fonts. Die Fotos liegen in `img/`.
Oben steht ein Hinweis „Entwurf“ (`.draft`), der vor dem Livegang entfernt wird; ebenso `<meta name="robots" content="noindex">`.

Live über GitHub Pages: https://emilianbleimn.github.io/My-Wok/

## Vor dem Livegang anpassen

1. **Speisekarte:** Gerichte, Nummern und Preise im `MENU`-Array im Skript sind **Beispielwerte**
   und müssen mit der echten Karte abgeglichen werden.
2. **Öffnungszeiten:** `HOURS` im Skript. Bekannt ist nur „schließt um 21:00“, die Anfangszeiten sind Platzhalter.
3. **Adresse & Telefon:** Abschnitt „So findest du uns“ (derzeit Musterstraße / 0000 000000).
4. **Impressum & Datenschutz:** Platzhalter in den Dialogen `#impressum` und `#datenschutz`.
